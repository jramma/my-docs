Frase standard para solicitar eliminación de datos. 

```bash

Hello,

I would like to request the deletion of all my personal data in accordance with the General Data Protection Regulation (GDPR).

I understand that by requesting the deletion of my personal data, I will lose access to any benefits, services, or features associated with my account, and that this action is irreversible.

Please confirm once this has been done.

Thank you

```
